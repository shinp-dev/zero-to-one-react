# Examples

重要な概念だけ、最小の`App.tsx`例を置きます。

使い方:

1. 先に自分で課題を実装する
2. 動作確認する
3. その後にexampleと比較する
4. 同じである必要はないので、設計差を説明する

| File | Concept |
|---|---|
| `06_state_counter.tsx` | useState |
| `08_state_design_filter.tsx` | derived data / minimal state |
| `09_sharing_state.tsx` | lifting state up |
| `12_context.tsx` | React 19 Context provider |
| `13_no_effect.tsx` | Effectなしの派生値 |
| `14_effect_timer.tsx` | external synchronization / cleanup |
| `15_task_board.tsx` | final integrated example |

Exampleは模範解答の唯一解ではありません。
